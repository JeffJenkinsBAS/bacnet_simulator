Put nssm.exe here.

This project does not ship the NSSM binary itself -- it has to come from
https://nssm.cc/download directly, since this deliverable was built in an
environment with no internet access to fetch it, and shipping an unverified
third-party binary inside the project wouldn't be appropriate anyway.

Steps:
1. Download the NSSM zip from https://nssm.cc/download (the "nssm 2.24"
   release, or newer if available).
2. Extract it. Inside, find win64\nssm.exe (or win32\nssm.exe on a 32-bit
   Windows install, which should be rare on a modern laptop).
3. Copy that nssm.exe into this folder, so the path is:
       <project root>\tools\nssm\nssm.exe
4. Run scripts\windows\install_service.bat.

If you'd rather not use a third-party tool at all, use
scripts\windows\install_scheduled_task.bat instead -- it uses only
Windows' built-in Task Scheduler. See PACKAGING.md for the tradeoffs
between the two methods.
